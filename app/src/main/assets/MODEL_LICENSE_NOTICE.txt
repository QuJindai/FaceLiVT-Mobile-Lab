FaceLiVTv2 XS / S / M model attribution

Models:
- FaceLiVTv2-XS
- FaceLiVTv2-S
- FaceLiVTv2-M

Author repository: https://github.com/novendrastywn/FaceLiVT
Model weights: https://huggingface.co/novendrastywn/FaceLiVT
Upstream code license: BSD 3-Clause
Hugging Face model repository license statement: CC BY-SA 4.0

This APK is an engineering validation prototype. The FaceLiVTv2 XS, S and M checkpoints are downloaded from the author's public Hugging Face repository during the reproducible CI build and converted to ONNX without training or weight modification beyond the upstream deployment reparameterization and format conversion.
